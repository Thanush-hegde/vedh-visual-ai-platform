# 🧠 VEDH Visual AI

> **Learn visually. Understand deeply. Grow intelligently.**

VEDH Visual AI is an **AI-powered visual learning platform** designed to transform the way students learn complex concepts. Instead of relying solely on static PDFs, notes, and traditional explanations, VEDH uses **Generative AI to turn learning content into structured, interactive, and visual experiences.**

## 🚀 What VEDH Does

VEDH brings multiple learning capabilities together in one platform:

* 📚 **AI Study Engine** — Generates structured notes, key points, brainstorming questions, and flashcards from study material.
* 🧠 **AI Concept Visualizer** — Converts complex concepts into interactive visual breakdowns with sequential steps, relationships, and interactive parameters.
* 📝 **AI-Assisted Assessment** — Helps create and support learning assessments.
* 👨‍🏫 **Teacher & Mentor Support** — Provides tools designed to help educators guide students and manage learning activities.
* 🔄 **Real-Time Synchronization** — Uses WebSockets to synchronize platform activity across connected devices.
* 👥 **Multi-Role Platform** — Designed for students, teachers, institutions, and professionals.

## 🤖 Powered by Generative AI

VEDH integrates the **Google Gemini API** as its AI learning engine. The backend securely connects to Gemini and uses it for tasks such as generating study notes and creating interactive concept visualisations. 

For example, the Concept Visualizer asks Gemini to generate a structured visualization containing **steps, relationships, interactive elements, and key takeaways**.

## 🎯 The Problem

Traditional digital learning often leaves students with **large amounts of text but limited understanding**. Complex topics can be difficult to visualize, revise, and practise effectively.

VEDH addresses this by turning learning material into **simplified explanations, structured knowledge, visual representations, and interactive learning experiences.**

## 💡 The Vision

VEDH aims to move learning from:

**Read → Memorize → Test**

to:

**Understand → Visualize → Interact → Practise → Master**
